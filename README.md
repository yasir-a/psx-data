# psx-data

Open-source toolkit for collecting and working with Pakistan Stock Exchange (PSX) data.

## Project Status

🚧 **Early development**

psx-data is currently under active development. APIs, data models, and project structure may change as the project evolves.

## Goals

The goal of psx-data is to provide a simple, reliable, and open-source way to collect and work with data published by the Pakistan Stock Exchange.

The project will focus on:

- PSX announcements
- Company information
- Financial data
- Market data
- Data extraction and processing
- Reusable Python interfaces
- Automated testing
- Clear documentation

The project aims to minimize unnecessary third-party dependencies and use Python's standard library wherever practical.

## Features

### Currently available

- Python package structure
- Automated unit tests
- GitHub Actions CI
- Protected `main` branch
- Pull-request-based development workflow

### Planned

- PSX announcements client
- Announcement data parsing

- Data storage
